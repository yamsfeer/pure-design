# 0005. 增加方向库(directions library)

- **状态**:✅ Accepted(已实现)
- **日期**:2026-08-13

## Context

上游 `prompts/directions.ts` 提供一份"美学方向菜单"(编辑/杂志感、现代极简、活泼/插画、科技/工具、奢华/精致、粗野/实验、人性化/亲切…),让 agent 明确锁定一个视觉方向,而不是模糊发挥。

我们目前靠设计系统 DESIGN.md + frontend-design 技能的"commit to one aesthetic direction"间接覆盖,但没有显式的方向库。

## Decision

**要**:引入一份方向库,作为第 2 步"装配"的一个可选输入。

## Consequences

- 第 1 步"澄清"时可让用户选方向;第 2 步"装配"时把方向说明注入系统提示词。
- 方向库是资产的一种,放 `assets/` 下(与设计系统 / 模板同级),新增一类资产。
- 与设计系统的关系:设计系统是"品牌契约"(颜色/字体/间距),方向库是"更上层的审美方向",二者可叠加,不冲突。
